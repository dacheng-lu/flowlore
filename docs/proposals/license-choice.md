# FlowLore license decision — draft

Status: **no license has been selected or activated**. The accompanying
[Apache-2.0 text](LICENSE-APACHE-2.0.txt) is a candidate for review, not a root LICENSE.

Proposed scope for the owner to approve: Apache-2.0 for original project source code,
schemas, original examples and original written documentation, subject to rights held
by third parties. Attribution, notices and license conditions for any incorporated
material remain applicable. Exclude branding assets, including `assets/logo.png`,
from this grant unless the owner explicitly chooses otherwise.

The catalog links to external projects and does not grant rights in those projects.
`docs/learning-paths/ihk-ki-automatisierung.md` identifies certificate topic labels
reproduced from a course provider; whether they may be republished or licensed must be
checked. An Apache grant could apply to original editorial additions only and cannot
grant the provider's rights. The four field-tested n8n descriptions summarize private
experience; no private source data or credentials should be published.

Repository commits attribute changes to one GitHub account, but commit metadata alone
does not establish ownership or rights in all content. Before adopting a root license,
the owner should confirm the scope, branding exclusion and course-material treatment;
then add the unmodified license text, a clear notice for exceptions, and update the
three README languages. Nothing here is legal advice or a determination of ownership.
